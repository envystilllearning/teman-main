# Teman Main — Full Playable MVP

Browser-based safe digital playground for young children. Indonesian, portrait-first, touch-first.

## Included
- Home / Playroom
- 3 worlds: Hewan, Buah, Bentuk
- 2 activities per world: Cari + Pasangkan
- 5-round find activities
- Match activity with 3 pairs
- Mascot Mimi
- Speech feedback using browser Web Speech API when available
- Local WebAudio feedback tones
- Audio toggle persisted in localStorage
- No login, backend, ads, chat, leaderboard, infinite scroll, or countdown

## Run
For best browser compatibility, serve the folder through a local HTTP server.

Example with Python:
`python -m http.server 8080`
Then open `http://localhost:8080`.

A static host such as GitHub Pages, Netlify, or Vercel also works.
